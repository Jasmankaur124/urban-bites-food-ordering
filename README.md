# 🍕 Urban Bites – Food Ordering Website

A front-end food ordering web app built with HTML, CSS and JavaScript. Browse the menu, add items to your cart, pay via UPI or card, and get an instant order confirmation. It runs entirely in the browser, with no server or database.

## ✨ Features

- Categorised menu: pizzas, beverages, pasta and desserts
- Cart with add, remove and quantity controls and a live total in ₹
- Cart saved in `localStorage`, so it persists across pages
- Checkout with UPI or card payment options
- Order confirmation page with a generated Order ID
- Direct order form with a loading indicator
- Customer reviews page
- Mood-based chatbot that suggests food (sweet, spicy, drink)
- Client-side login check on every page

## 🛠️ Tech Stack

HTML5 · CSS3 · JavaScript (ES6) · Web Storage API
